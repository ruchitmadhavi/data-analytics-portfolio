# 🎮 Steam Games Analytics

An end-to-end data analytics project analyzing Steam games
using Python, SQL, and Tableau.

## Tools Used

- Python
- Pandas
- NumPy
- SQLite
- SQL
- Tableau

## Analysis

The project analyzes:

- Number of games released over time
- Game genres
- Price distribution
- Game recommendations
- Most recommended games
- Average game price

## Data Cleaning

Python was used to:

- Handle missing values
- Validate data types
- Clean price data
- Process release dates
- Convert genre lists into individual records

## SQL Analysis

SQL was used to calculate:

- Games released per year
- Average game price
- Most expensive games
- Most recommended games
- Other aggregated metrics

## Tableau Dashboard

The final dashboard provides interactive:

- Genre filtering
- Price filtering
- Release-year filtering
- Interactive charts
- KPI metrics
